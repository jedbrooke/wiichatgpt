# Goal
1. get chatgpt running on a nintento wii. Ok not actually chatgpt, but a small ~1B model. (if we're really comitting to the bit we could run GPT2, but that's before they were named chatgpt anyway). The name is also a play on 'wechat' the popular chinese messaging app. 
2. how we're gonna do it: use per layer embeddings like Gemma3n (see also https://github.com/slvDev/esp32-ai), we'll use the gpu/system ram for 64MB of our fast LUT, and disk (prob usb or sd card at first for simpler, but actual DVD eventually) for the weights. 
3. GPU ACCELERATION. We are going to use the GPU for running the model. Even though the Wii gpu is NOT programmable, it only handles some fixed function graphics transform type workloads. HOWEVER, many of these map to matrix multiplications, and matmul is matmul, so that means we can run a transformer (probably). We'll probably start of testing on the CPU.
4. we'll probably do a fork of llama.cpp (we'll briefly explore other inference stacks too, potentially even from scratch if needed) with a custom kernel for the wii gpu.
5. model will be a custom trained model (or fine tune), around 1B, likely INT8/4 (wii lacks any fp16 etc, only has fp32 which is likely too slow). Instead of going for a general purpose model, we plan to train/fine-tune a model on wii trivia, popular wii games, etc. prob yoink some wikis (jake can handle the training)
6. basic chat interface, prob use some graphics lib (maybe SDL 1/2? idk the wii brew scene but I know older SDL supports wii) that will give us usb keyboard for free, but for the *authentic* wii experience, text will be entered with an on screen keyboard and the wii pointer, just as Nintendo intended.
